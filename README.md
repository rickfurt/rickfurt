### Hi, I'm Ricardo 👋

Full Stack Developer in Sydney. I build web apps end to end, mostly Next.js and React on the front, Node and Express on the back, running on AWS.

A lot of my work is 3D and interactive: product experiences built with Three.js and React Three Fiber. The kind of page that reacts as you scroll and still loads fast.

I use AI dev tools (Claude Code, Copilot, ChatGPT) every day. Used well, they cut my cycle time by around 25-30%, mostly on boilerplate and test scaffolding.

My degree is in IT with a cybersecurity specialisation, so I think about auth and API security while I build, not after.

#### Working with

`TypeScript` · `React` · `Next.js` · `Node.js` · `Express` · `Three.js` · `Tailwind` · `Prisma` · `GraphQL` · `AWS (CDK, Lambda, AppSync)` · `Docker` · `GitHub Actions`
